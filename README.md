# UHSM: A Unified Hierarchical Spatial Multi-scale Framework for Multi-factor Oceanic Forecasting

PyTorch Implementation of UHSM

## Requirements

* Python >= 3.8 (3.8 recommended)
* PyTorch (tested with PyTorch 2.0.0)
* CUDA (tested with CUDA 11.8)
* numpy
* pandas == 2.0.0 (for pickle use)
* scikit_learn
* reformer-pytorch == 1.4.4
* PyWavelets == 1.4.1
